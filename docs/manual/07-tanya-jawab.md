# Tanya Jawab

**Saya lupa password.**
Di halaman masuk tekan **Lupa password**, isi nomor HP, lalu masukkan kode dari WhatsApp. Bila
kode tidak datang, hubungi admin sekolah untuk reset password.

**Nomor HP saya berganti.**
Tambahkan nomor baru di **Menu › Profil** selagi masih bisa masuk, atau minta admin mengubahnya.
Nomor yang dipakai untuk masuk harus nomor yang terdaftar.

**Tombol Install Aplikasi tidak muncul.**
Gunakan Chrome versi terbaru (Android) atau Safari (iPhone), lalu ikuti *Cara Install Aplikasi* di
halaman masuk.

**Notifikasi tidak muncul di HP.**
Buka **Notifikasi › Aktifkan notifikasi** dan pilih **Izinkan**. Bila sebelumnya pernah ditolak,
buka pengaturan situs di browser, ubah izin Notifikasi menjadi *Izinkan*, lalu muat ulang. Di
iPhone, pasang aplikasi di layar utama terlebih dahulu.

**Anak saya tidak muncul / data anak salah.**
Hubungi admin sekolah agar akun Anda dihubungkan ke data anak yang benar.

**Rapor belum bisa dibuka.**
Rapor baru bisa dibuka wali santri setelah dikunci (final) oleh sekolah.

**Sudah bayar QRIS tapi tagihan belum lunas.**
Tunggu beberapa saat dan muat ulang halaman Tagihan. Bila tetap belum lunas, simpan bukti
pembayaran dari aplikasi e-wallet/m-banking Anda dan hubungi bendahara.

**Presensi hari ini terlanjur salah.**
Wali kelas bisa mengubahnya sampai pukul 23.59 di hari yang sama. Setelah itu, minta admin
mengoreksi.

**Aplikasi menampilkan "sedang dipulihkan" atau "pemeliharaan".**
Sekolah sedang memulihkan data dari backup. Tunggu beberapa menit, lalu masuk kembali.

**Siapa yang bisa saya hubungi?**
Admin/tata usaha sekolah untuk akun dan data; bendahara untuk tagihan dan pembayaran; wali kelas
untuk presensi dan rapor.
