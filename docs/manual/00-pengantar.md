# Tentang TARBIYAH

TARBIYAH adalah aplikasi sekolah untuk pondok pesantren dan madrasah. Semua kegiatan harian ada
di satu aplikasi:

- **Presensi** santri setiap hari, oleh wali kelas.
- **Akademik**: PR & tugas, nilai, dan rapor.
- **Keuangan**: tagihan SPP, pembayaran tunai/transfer/QRIS, dan bukti bayar lewat WhatsApp.
- **Informasi**: pengumuman, kalender, jadwal pelajaran, dan notifikasi.

Aplikasi dibuka lewat browser di HP atau komputer, dan bisa **dipasang di layar utama HP** seperti
aplikasi biasa (tanpa Play Store).

**Alamat aplikasi:** https://tarbiyah.minhajussunnah.web.id

## Siapa melihat apa

Setiap orang hanya melihat menu dan data sesuai perannya. Satu orang bisa punya beberapa peran
sekaligus (misalnya guru yang juga wali kelas dan orang tua santri) dengan **satu akun**.

| Peran | Yang bisa dilakukan |
| --- | --- |
| Wali santri | Melihat presensi, PR, nilai, rapor final, dan tagihan **anaknya sendiri**; membayar SPP |
| Guru pengajar | Memberi PR, mengisi nilai, dan mengisi rapor mapel yang diajarnya |
| Wali kelas | Mengisi presensi harian kelasnya; mengisi aspek & catatan rapor kelasnya |
| Bendahara | Mengelola tagihan, mencatat pembayaran, mengirim bukti WA, laporan keuangan |
| Kepala sekolah | Melihat semua kelas, mengunci rapor (final), pengumuman, kalender, laporan keuangan |
| Admin | Semua di atas, ditambah data sekolah, pengguna, pengaturan, dan backup |

> **Privasi.** Wali santri hanya bisa melihat data anaknya sendiri. Jangan membagikan password dan
> jangan mengirim tangkapan layar berisi data santri ke grup umum.

## Cara membaca panduan ini

Tombol dan menu ditulis **tebal**, misalnya **Simpan presensi**. Tanda **›** berarti "lalu pilih",
misalnya **Menu › Profil**. Gambar di panduan memakai data contoh, bukan data santri sungguhan.
